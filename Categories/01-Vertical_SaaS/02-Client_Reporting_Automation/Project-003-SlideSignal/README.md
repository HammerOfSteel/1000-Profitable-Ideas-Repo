## 📖 Overview
Converts recurring campaign or ops metrics into polished slide-ready summaries so agencies can communicate outcomes without rewriting the same commentary every reporting cycle.

## 🛑 The Problem
Even when agencies have dashboards, they still spend manual time translating raw charts into stakeholder-friendly narrative updates, key takeaways, and suggested next steps.
